Connect an agent

Optional. The built-in coach handles intervals, recaps and Easier/Harder. An agent also reads your HR trend and speech and edits the workout mid-ride.

  1. Install the extra: pip install "openspin[mcp]"
  2. Keep openspin serve running.
  3. Add the MCP server to your agent.

Claude Code:

claude mcp add openspin -- openspin mcp

Codex (~/.codex/config.toml):

[mcp_servers.openspin]
command = "openspin"
args = ["mcp"]

Any other MCP client: run openspin mcp over stdio. Without MCP, any tool can use the HTTP API with the token in ~/.openspin/token.

Then ask: "Coach my ride. Read the playbook, wait for events, keep me in zone." The agent loops on wait_for_events, which wakes it only for segment summaries, your presses and speech, and alerts. The ride header shows wakes and cost.

The coaching playbook and safety limits are in docs/COACHING.md; the API is in docs/PROTOCOL.md.
